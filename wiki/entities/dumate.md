# 百度搭子（dumate）

**一句话**：百度推出的 AI 助手产品，在抖音视频里被当作“帮我去 GitHub 找开源工具并给出入口”的执行代理。

## 素材中出现的信息

- 抖音视频的话题标签：`#百度搭子`、`#办公就用dumate`。
- 界面特征（见 [frame-05](../../sources/2026-11-07-douyin-typewords/assets/frames/frame-05.png)）：输入框 + “默认权限” + 工作区文件夹选择；下方任务分类有「自媒体运营 / 求职工作台 / 生成PPT / 数据处理 / 金融分析 / 文档处理 / 搭建应用」；任务卡可“换一换”。
- 用法：输入一句自然语言任务（找 GitHub 上的 TypeWords 在线工具），由搭子执行。
- 系列化证据：推荐人「猫吃小鱼」的 18 个作品里，几乎每期都出现 `#百度搭子` 或 `#豆包`，说明这是其固定选题/演示格式（见 [猫吃小鱼](maochixiaoyu.md)）。

## 为什么值得记录

它是“**AI 助手从聊天框变成工具入口**”的一个具体案例：用户不需要知道 GitHub 搜索、README、部署地址，只需要描述目标。详见 [AI 助手即工具入口](../concepts/ai-as-tool-router.md)。

## 待验证

- “搭子 / dumate”的官方产品名、能力边界与定价，本 wiki 尚无一手资料 **（待验证）**。
- 同系列视频里「搭子」与「豆包」交替出现，二者是同一产品的不同入口还是两个产品，**（待验证）**。
- 视频中“优先用搭子”是创作者的个人偏好，不代表产品对比结论。
